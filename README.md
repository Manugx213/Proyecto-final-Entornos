# Práctica ENTORNOS DE DESARROLLO

## Autor

Manuel García García

## Versión

1.0

## Descripción

En esta práctica se ha desarrollado una clase llamada `Rectangulo` que permite calcular el área y el perímetro de un rectángulo a partir de sus dimensiones.

Además, se han creado pruebas unitarias con JUnit para verificar el correcto funcionamiento de los métodos implementados.

## Funcionalidades

* Cálculo del área de un rectángulo.
* Cálculo del perímetro de un rectángulo.
* Verificación mediante pruebas unitarias.
* Generación de documentación JavaDoc.

## Documentación JavaDoc

La documentación se ha generado utilizando la herramienta JavaDoc incluida en el JDK.

La documentación incluye:

* Autor de las clases.
* Versión del proyecto.
* Parámetros de los métodos y constructores.
* Valores devueltos por los métodos.

## Clases incluidas

### Rectangulo

Clase principal que representa un rectángulo mediante los atributos:

* `ancho`
* `alto`

Métodos disponibles:

* `area()`: calcula el área del rectángulo.
* `perimetro()`: calcula el perímetro del rectángulo.

### RectanguloTest

Clase de pruebas unitarias que verifica:

* El cálculo correcto del área.
* El cálculo correcto del perímetro.
